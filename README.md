# Next Go Orders

Página institucional de vendas do sistema de agendamento e pedidos **Next Go Orders**, desenvolvido pela **FC Soluções Digitais** para o ecossistema da **Guia Panorama**.

O site apresenta o sistema de cardápio digital e gerenciamento de pedidos para estabelecimentos, incluindo demonstração dos recursos, planos, formas de contratação e canais de atendimento. Os clientes podem conhecer o funcionamento do sistema, agendar uma consultoria e encaminhar pedidos pelo canal de vendas.

Entre os recursos apresentados estão cardápio digital personalizado, pedidos online, cálculo de frete, pagamentos online, acompanhamento da operação e organização das entregas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Google Analytics / Google Tag Manager
- Meta Pixel
- Cloudflare Web Analytics
- SVG e imagens otimizadas para a interface

## Estrutura do projeto

- `index.html`: conteúdo, estrutura semântica e dados estruturados da página
- `assets/css`: estilos da interface e do aviso de consentimento
- `assets/js`: interações da página e gerenciamento de consentimentos
- `assets/img`: logotipo e imagens ilustrativas
